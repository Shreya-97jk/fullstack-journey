# 12-Week Fullstack Learning Plan

## Week 1 — Bootstrap, Terminal, Git, Claude Code
- Day 1: Terminal commands, environment variables, Git init, first commit, .gitignore, Claude Code basics
- Day 2: Git branching, merging, diffs, log, stash
- Day 3: GitHub: remote, push, pull, clone, fork
- Day 4: Review + mini-project (personal README repo)
- Day 5: Wrap-up quiz + retrospective

## Week 2 — JavaScript Fundamentals I
- Variables, types, operators, conditionals, loops

## Week 3 — JavaScript Fundamentals II
- Functions, scope, closures, arrays, objects

## Week 4 — JavaScript in the Browser
- DOM, events, fetch API

## Week 5 — Node.js & npm
- Modules, package.json, scripts, Express basics

## Week 6 — Building a REST API
- Routes, middleware, JSON responses, Postman

## Week 7 — React Fundamentals
- Components, JSX, props, state

## Week 8 — React Advanced
- useEffect, forms, lifting state, React Router

## Week 9 — Databases
- SQL basics, PostgreSQL, connecting from Node

## Week 10 — Full-stack Integration
- React + Express + Postgres end-to-end

## Week 11 — Deployment
- Environment variables, Railway/Render, CI basics

## Week 12 — Capstone Project
- Build and ship a small full-stack app
